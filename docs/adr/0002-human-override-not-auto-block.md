# ADR 0002: Failed four-fifths goes to a human with a written reason

Status: accepted. Context: the measured run shows the ratio fails from noise at small n. Auto-blocking would stall fair shortlists; auto-passing would hide real bias. Decision: a failed audit needs a named reviewer's written override, logged in the hash chain. A name-swap failure should be treated as a defect to fix, not overridden. Consequence: reviewers must read the p-value and intervals.
